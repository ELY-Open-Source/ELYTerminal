# What it does

English / [中文](../zh_cn/features.md)

- The terminal runs on `alacritty_terminal`: 256 colors and truecolor, bold, dim, italic, five underline styles, wide characters and combining marks. Box drawing, block elements and powerline shapes are drawn as geometry, so lines join across cells. Keys follow xterm and the kitty keyboard protocol, and on Windows win32-input-mode, as Windows Terminal sends them, so herdr's shortcuts work; input methods compose at the cursor; programs can track the mouse; pastes are bracketed when a program asks; OSC 8 and plain links open with the link press in [keys](keys.md); inside herdr, herdr opens them, web links only, whole where its pane wraps them, and with Shift the terminal opens what it sees; find searches the scrollback. Shift+Enter makes a new line in codex and Claude Code. On Windows every session runs on Microsoft's OpenConsole, which comes in the zip, so full-screen programs get the mouse.
- Images: kitty's graphics protocol, sent directly, from a file or from shared memory, as PNG, RGB or RGBA; placed at the cursor, through Unicode placeholders or beside another image, under or over the text; animated frame by frame. A hidden session gives its images' GPU memory back until it shows again.
- The clipboard through kitty's clipboard protocol, OSC 5522: a program writes text, an image or files at once; a read of what the clipboard holds asks you first, showing what it would read, and Allow for this session lets that program read again unasked, while a read that only lists the types answers at once. Under mode 5522 a paste hands the program the clipboard's types and a one-time password instead of text; within 10 seconds that password, the newest paste's, reads the clipboard as it then is, once, unasked.
- History packs small while it rests, and unpacks as you scroll, search or select in it: 10,000 lines of shell output took 85 to 95% less memory in our measures; lines that change color at every character pack little.
- Speed: rows with many colors draw about three times as fast, plain output reaches the screen about 30% faster, and kitty graphics payloads decode with SIMD.
- Image tools size their pictures on every system: the terminal answers a cell's size in pixels, CSI 16 t, which yazi asks on Windows.
- A scrollbar along the terminal's right edge scrolls its history, even while a program takes the wheel.
- Shell integration for zsh, bash, fish and PowerShell, on Windows for Git for Windows' bash and `sh` too, and for the bash, zsh or fish a Shell of `wsl` starts, so Files and Git follow a WSL or Git Bash session: each prompt reports its folder and title, and OSC 133 marks each prompt, each command and its exit status. On Windows PowerShell's `cd` also takes Git Bash's drive paths where no such path lies on the current drive: `cd /e` goes to `E:\`, `cd /c/Users` to `C:\Users`. On Wayland, Shift and Ctrl+Shift shortcuts hold when an input method such as fcitx5 forwards a modifier key without the compositor's modifier state. zsh's prompt, drawn again as the window resizes, leaves no copy in the history. A cmd session, or `cmd` typed at PowerShell's prompt, marks its prompts and reports its folder, and a command's start clears the last one's failure, so the row and Ely stay calm while ssh or a nested shell runs.
- Ely peeks over the window's top edge, or up from its bottom left when the window leaves her no room above it, and moves all the time: she breathes, sways and blinks. She follows your sessions: she hops when a program waits on you, shakes at an error, cheers a finish, reads along while a program works, and dozes when all is calm for long. Press her and she winks, waking her from a doze. Drag her along the edge to move her. Settings › Terminal › Ely turns her off.
- Sessions: new, close and switch. A right press on a row duplicates it, in the shell it runs and the folder it last reported, or closes it, and a drag moves a row to another place; Settings › Terminal turns either off. A bell marks a hidden session's row and makes no sound. A row's mark shows what its programs report through OSC 7501, OSC 9;4 or herdr: waiting on you, an error, work with its progress, done or idle, else a failed last command. The mark is 3 by 3 dots: work ripples and waiting dips while they last. Hover over the mark lists each report.
- Notifications: while the window is in the background or the session hidden, a session that starts waiting, finishes or fails, a command that ran 5 seconds or more ending, and a program's OSC 9, 777 or 99, post a system notification, one a session every 3 seconds at most; a press shows the session. On macOS only the app bundle posts them, not `cargo run`.
- Cmd-Up and Cmd-Down, Ctrl-Shift-Up and Ctrl-Shift-Down off macOS, jump to the prompt before or after the view's top.
- Natural text editing on macOS, off by default in Settings › Terminal: Option-Left and Option-Right move by word, Option-Backspace and Option-Delete delete by word, Command-Left and Command-Right move to the line's ends, and Command-Backspace and Command-Delete delete to them, sent as the editing bytes the shell expects.
- Option as Alt in Settings › Terminal turns the chosen macOS Option keys into the terminal's Alt, with an input method such as Pinyin selected too; an Option key not chosen still types special characters.
- A button at each end of the title bar hides or shows its side column, and a drag on the border between a side column and the terminal resizes it; the window opens as it was left, at the size and widths it was left at, and on macOS, Windows and X11 on the display and at the place it was left. On Windows and Linux a gear beside the right one opens Settings.
- Files shows the session's folder as a tree with Git's marks. Inside herdr the folder is that of herdr's focused pane. With Settings › Terminal › Files menu on, a right press on a name opens it, starts a session in its folder or copies its path. While Files shows, its open folders and Git's marks are read again each second, so a file a program or an agent makes shows without a prompt.
- Git shows the branch, stages, unstages, discards, commits, lists recent commits and opens diffs, all through the `git` command line.
- Themes: Ely Dark, Ely Light, Catppuccin Mocha, Macchiato, Frappé and Latte, Tokyo Night, Dracula, Nord, Gruvbox Dark, Rosé Pine, Solarized Light, One Light and Kanagawa Wave, then New theme, which makes a theme of your own from Ely Dark whose name and colors you set; the built-in ones never change. A background image goes under the terminal at the background's opacity. A second theme can take over while the system is dark. On Omarchy 4, an Omarchy theme follows the system's theme as it switches, and is the default there.
- Interface font and size in Settings › Appearance: any installed family, with a sample line, and 12 to 16 px for every window's chrome; the terminal keeps its own font.
- On Windows, Settings › Terminal › Explorer menu adds Open in ELYTerminal to a folder's right-click menu, for you alone, and removes it; on Windows 11 it sits under Show more options. `elyterminal FOLDER` starts the first session in FOLDER on every system; cmd, which refuses a network share as its folder, says so and starts in the Windows folder. When launched without arguments from Windows Terminal (including Open in Terminal on Windows 11), the first session uses the directory Windows Terminal supplies, ahead of Start in.
- Background opacity and blur: NSVisualEffectView on macOS, acrylic on Windows, or on Windows 11 from build 22621 Mica or Mica Alt, as Settings › Appearance › Backdrop says, `ext_background_effect_v1` or `org_kde_kwin_blur` on Wayland, `_KDE_NET_WM_BLUR_BEHIND_REGION` on X11, which KWin reads. Blur shows only while the opacity is under 100%. Hyprland blurs only while its own `decoration:blur:enabled` is on, and Omarchy 4.0.4 turns it off; to turn it on there, add `hl.config({ decoration = { blur = { enabled = true } } })` to `~/.config/hypr/looknfeel.lua`.
