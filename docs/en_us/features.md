# What it does

English / [中文](../zh_cn/features.md)

- The terminal runs on `alacritty_terminal`: 256 colors and truecolor, bold, dim, italic, five underline styles, wide characters and combining marks. Box drawing, block elements and powerline shapes are drawn as geometry, so lines join across cells. Keys follow xterm and the kitty keyboard protocol, and on Windows win32-input-mode, as Windows Terminal sends them, so herdr's shortcuts work; input methods compose at the cursor; programs can track the mouse; pastes are bracketed when a program asks; OSC 8 and plain links open with the link press in [keys](keys.md); inside herdr, herdr opens them, web links only, whole where its pane wraps them, and with Shift the terminal opens what it sees; find searches the scrollback. Shift+Enter makes a new line in codex and Claude Code. On Windows every session runs on Microsoft's OpenConsole, which comes in the zip, so full-screen programs get the mouse.
- Images: kitty's graphics protocol, sent directly, from a file or from shared memory, as PNG, RGB or RGBA; placed at the cursor, through Unicode placeholders or beside another image, under or over the text; animated frame by frame. A hidden session gives its images' GPU memory back until it shows again.
- The clipboard through kitty's clipboard protocol, OSC 5522: a program writes text, an image or files at once; a read of what the clipboard holds asks you first, showing what it would read, and Allow for this session lets that program read again unasked, while a read that only lists the types answers at once. Under mode 5522 a paste hands the program the clipboard's types and a one-time password instead of text; within 10 seconds that password, the newest paste's, reads the clipboard as it then is, once, unasked.
- History packs small while it rests, and unpacks as you scroll, search or select in it: 10,000 lines of shell output took 85 to 95% less memory in our measures; lines that change color at every character pack little.
- Speed: rows with many colors draw about three times as fast, plain output reaches the screen about 30% faster, and kitty graphics payloads decode with SIMD.
- Image tools size their pictures on every system: the terminal answers a cell's size in pixels, CSI 16 t, which yazi asks on Windows.
- A scrollbar along the terminal's right edge scrolls its history, even while a program takes the wheel.
- On Windows, a wheel notch sends one mouse report to a program tracking the mouse; local history still scrolls the system's line count. Fractional notches accumulate, and Shift keeps its local scrolling behavior.
- On Windows, a paste with no text still notifies a program using bracketed paste, so apps such as OpenCode can read a clipboard image themselves.
- On Windows, typing hides the mouse pointer over the window until the mouse moves, as in Windows Terminal; it no longer blinks back at each key.
- Shell integration for zsh, bash, fish and PowerShell, on Windows for Git for Windows' bash and `sh` and MSYS2's fish too, and for the bash, zsh or fish a Shell of `wsl` starts, so Files and Git follow a WSL or Git Bash session: each prompt reports its folder and title, and OSC 133 marks each prompt, each command and its exit status. On Windows PowerShell's `cd` also takes Git Bash's drive paths where no such path lies on the current drive: `cd /e` goes to `E:\`, `cd /c/Users` to `C:\Users`. On Wayland, Shift and Ctrl+Shift shortcuts hold when an input method such as fcitx5 forwards a modifier key without the compositor's modifier state. zsh's prompt, drawn again as the window resizes, leaves no copy in the history. A cmd session, or `cmd` typed at PowerShell's prompt, marks its prompts and reports its folder, and a command's start clears the last one's failure, so the row and Ely stay calm while ssh or a nested shell runs.
- Ely peeks over the window's top edge, or up from its bottom left when the window leaves her no room above it, and moves all the time: she breathes, sways and blinks. She follows the session you are in: she hops when its program waits on you, shakes at its error, cheers its finish, reads along while it works, and dozes when it is calm for long. The other sessions keep their own marks in the sessions column. Press her and she winks, waking her from a doze. She hides with the window when it is minimized, GNOME's X11 among the desktops. Drag her along the edge to move her. Settings › Terminal › Peek low keeps her down to her hair and ahoge until the pointer comes over her, for TUIs that use the window's top edge. Settings › Terminal › Ely turns her off.
- Sessions: new, close and switch. Groups gather rows under a name: a right press on a row puts it in a new group, whose name opens to type, moves it to another group or takes it out; a double press on a group's name renames it, and its menu ungroups it; a new session joins the shown session's group. Settings › Terminal › Restore sessions, on by default, opens the sessions you left at the next start: their panes and split sizes, programs, folders, names and groups, not their scrollback, nor a pane `-e` started, nor a session Windows handed over; a start given a folder or a program opens only that. A right press on a row renames it, duplicates it, in the shell it runs and the folder it last reported, or closes it, and a drag moves a row to another place; Settings › Terminal turns either off. The arrow beside + opens profiles, as Windows Terminal's: your own, each a name, a command line with its arguments and a folder, set in Settings › Terminal › Profiles, then the shells this system holds, on Windows PowerShell, cmd, Git Bash and each WSL distribution but Docker Desktop's, elsewhere each shell `/etc/shells` lists. On Windows, Shell and a profile refuse a program that opens a window of its own, as `git-bash.exe` does, and name Git's `bin\bash.exe` instead. A profile that names a program alone, or `wsl -d NAME`, keeps its shell integration; other arguments run as written, and that session reports no folder. A right press on the terminal's title renames the shown session too. A bell marks a hidden session's row and makes no sound. A row's mark shows what its programs report through OSC 7501, OSC 9;4 or herdr: waiting on you, an error, work with its progress, done or idle, else a failed last command. The mark is 3 by 3 dots: work ripples and waiting dips while they last. Hover over the mark lists each report.
- Notifications: while the window is in the background or the session hidden, a session that starts waiting, finishes or fails, a command that ran 5 seconds or more ending, and a program's OSC 9, 777 or 99, post a system notification, one a session every 3 seconds at most; a press shows the session. On macOS only the app bundle posts them, not `cargo run`.
- Cmd-Up and Cmd-Down, Ctrl-Shift-Up and Ctrl-Shift-Down off macOS, jump to the prompt before or after the view's top.
- Natural text editing on macOS, on by default in Settings › Terminal: Option-Left and Option-Right move by word, Option-Backspace and Option-Delete delete by word, Command-Left and Command-Right move to the line's ends, and Command-Backspace and Command-Delete delete to them, sent as the editing bytes the shell expects.
- Option as Alt in Settings › Terminal turns the chosen macOS Option keys into the terminal's Alt, with an input method such as Pinyin selected too; an Option key not chosen still types special characters.
- A button at each end of the title bar hides or shows its side column, and a drag on the border between a side column and the terminal resizes it; the window opens as it was left, at the size and widths it was left at, and on macOS, Windows and X11 on the display and at the place it was left. On Windows and Linux a gear beside the right one opens Settings. Full screen hides the title bar and the columns' headers; leaving it brings them back. On a Mac with a Touch Bar, closing Settings or a window no longer crashes the app.
- Files shows the session's folder as a tree with Git's marks. Inside herdr the folder is that of herdr's focused pane. A name dragged onto the terminal types its path, as a file dropped from the desktop does. With Settings › Terminal › Files menu on, a right press on a name opens it, starts a session in its folder or copies its path, and a right press on the Files tab reveals Choose folder for a new session…, which starts the shown session's shell in a folder you pick; a second right press closes it. While Files shows, its open folders and Git's marks are read again each second, so a file a program or an agent makes shows without a prompt. Inside `ssh`, Files lists the remote folder once the remote shell reports it through OSC 7, over an ssh connection of its own that asks no password: a key, an agent or your shared connection must reach the host. It shows no Git marks there. Most shells send no OSC 7 over ssh; add to the remote `~/.bashrc` `PROMPT_COMMAND='printf "\e]7;file://%s%s\a" "$HOSTNAME" "${PWD//%/%25}"'`, or to `~/.zshrc` `precmd() { printf "\e]7;file://%s%s\a" "$HOST" "${PWD//\%/%25}" }`.
- Git shows the branch, stages, unstages, discards, commits, lists recent commits and opens diffs, all through the `git` command line.
- Themes: Ely Dark, Ely Light, Catppuccin Mocha, Macchiato, Frappé and Latte, Tokyo Night, Dracula, Nord, Gruvbox Dark, Rosé Pine, Solarized Light, One Light and Kanagawa Wave, then New theme, which makes a theme of your own from Ely Dark whose name and colors you set; the built-in ones never change. A background image goes under the terminal at the background's opacity. A second theme can take over while the system is dark. On Omarchy 4, an Omarchy theme follows the system's theme as it switches, and is the default there.
- The terminal's font in Settings › Appearance: a family, fallbacks, a CJK font that Chinese, Japanese and Korean characters draw in before the family, a size, a weight from 100 to 900, bold 300 heavier up to 900, line height and ligatures. Antialiasing, on Windows and Linux, is Grayscale by default, as Windows Terminal draws, or Subpixel, which draws only on an opaque window. The cursor glides to its new cell; Settings › Appearance › Cursor › Glide turns it off.
- Interface font and size in Settings › Appearance: any installed family, with a sample line, and 12 to 16 px for every window's chrome; the terminal keeps its own font.
- On Windows, Settings › Terminal › Explorer menu adds Open in ELYTerminal to a folder's right-click menu, for you alone, and removes it; on Windows 11 it sits under Show more options. The same Add puts this copy's folder on your user `PATH`, so `elyterminal .` typed in Explorer's address bar opens a session in that folder; Remove takes both away. `elyterminal FOLDER` starts the first session in FOLDER on every system; cmd, which refuses a network share as its folder, says so and starts in the Windows folder. The folder may also follow `--working-directory`, `-d` or `--startingDirectory`, as xdg-terminal-exec and Windows Terminal pass it.
- Background opacity and blur: NSVisualEffectView on macOS, acrylic on Windows, or on Windows 11 from build 22621 Mica or Mica Alt, as Settings › Appearance › Backdrop says, `ext_background_effect_v1` or `org_kde_kwin_blur` on Wayland, `_KDE_NET_WM_BLUR_BEHIND_REGION` on X11, which KWin reads. The opacity runs from 0% to 100%, and blur shows only while it is under 100%. Hyprland blurs only while its own `decoration:blur:enabled` is on, and Omarchy 4.0.4 turns it off; to turn it on there, add `hl.config({ decoration = { blur = { enabled = true } } })` to `~/.config/hypr/looknfeel.lua`.
- Background image: a picture at Settings › Appearance › Background image, drawn at the background's opacity where Picture scope says, under the terminal's column or under the whole window, the title bar included. A column's header can hold the terminal wider than its width setting, and the picture follows the terminal itself. The picture keeps its colors: while one is set, the columns' glass is 0, so a window-wide picture shows through them. Its size, position and repeat are CSS's: `cover`, `contain`, `fill`, `auto` or a width and a height such as `51% auto`; a place such as `right top` or `125% 100%`; and no repeat, repeat across, down or both, which `settings.json` spells `no_repeat`, `repeat_x`, `repeat_y` and `repeat`. The picture stays inside its box. A gradient paints over the picture: its angle in degrees, 0 upward and turning clockwise, and two colors, `#rrggbbaa` among them. Picture opacity fades the picture, 0 to 1; a mask, a switch, an angle, two to sixteen stops whose alpha is the mask, and the mask's size and position within the picture, fades it. A straight edge comes from the mask's box: outside it the picture is clear, so a gradient whose alpha reaches 0 at the edge the picture appears from fades it in, where a stop that is not transparent there cuts it.
- Clear, Cmd-K or Ctrl-Shift-K, drops the history and the screen above the prompt; on Windows, where ConPTY keeps the screen, the history alone.
- Every shortcut can be changed in Settings › Terminal › Shortcuts; see [Keys](keys.md). With Copy given Ctrl-C, Ctrl-C copies a selection and, with none, reaches the program, as in Windows Terminal.
- Updates install from Settings › Terminal › Updates: Update downloads the newer release's file for your copy, checks it against the SHA-256 GitHub lists, and puts it in place: on macOS the app from the disk image, its signature and team checked; on Windows the zip's files; on Linux the AppImage, the tarball's binary, or the DEB or RPM through `apt-get` or `dnf` as root through `pkexec`. Restart then opens the new release, asking first while a program runs.
- On macOS a folder dropped on the app's icon opens a session there, the app running or not.
- With the paddings at 0, a program's background reaches the terminal's bottom and right edges. A bottom row holding a prompt, the default background or a powerline glyph keeps its background in its cells, as Ghostty does, so a prompt or nvim's status line does not run down to the edge.
- The menu beside + ends with Choose folder for a new session…; a profile in Settings › Terminal › Profiles keeps a folder for next time.
- Command line control, off by default in Settings › Terminal: `elyterminal ctl sessions` lists each session's panes, `elyterminal ctl read SESSION [LINES]` prints a session's last lines, `elyterminal ctl send SESSION TEXT` types text and Enter, and `elyterminal ctl key SESSION ctrl-c` presses keys, so scripts and agents can read and drive a running terminal. It speaks to the app over a loopback port named, with a token, in a file only your account reads; on Windows pipe or redirect its output, since the release is a window program.
- Programs can tell the terminal by `TERM_PROGRAM=elyterminal` and `TERM_PROGRAM_VERSION`; kitty graphics answer the protocol's own query, and no `KITTY_WINDOW_ID` is set, since that names kitty itself.
- Panes: a session splits right or down, each pane its own terminal running the pane's program again in its folder, a session Windows handed over the default shell; the pane that holds the keys has the stronger border, and the row's mark, the title, Files, Git and Duplicate follow it. Several panes stand apart, each in its border, with a gap between them and no line of its own; a drag on the gap resizes them, and Move pane left, right, up and down swap the focused pane with its neighbor; see [Keys](keys.md).
- A selection dragged past the grid's top or bottom scrolls the history and goes on selecting; so does a wheel or trackpad scroll while you drag.
- A paste of more than one line asks first while the program has not asked for bracketed paste; Settings › Terminal › Ask before a risky paste, on by default.
- Quit, closing the window or closing the last session asks first while a program runs in a pane, and not for a shell at its prompt; Settings › Terminal › Ask before closing running sessions, on by default. Cmd-Q quits cleanly on macOS.
- `elyterminal [-d FOLDER] -e PROGRAM [ARG...]` runs PROGRAM as the first session, without shell integration; its exit closes its pane, the last pane its session, and the last session the window.
- On Windows, Settings › Terminal › Default terminal makes ELYTerminal open console programs started without a terminal, from Run and other apps, for you alone; Restore gives the choice back to Windows. A console program it takes over brings ELYTerminal's window to the front. Windows' own list of default terminals shows packaged apps only, so ELYTerminal is not listed there.
