# 快捷键

[English](../en_us/keys.md) / 中文

设置 › 终端 › 快捷键 列出全部快捷键，按本平台的绑定，并且都可以更改：点「更改」后按下的第一个键即为该命令的新快捷键，Esc 保留原键，退格键让该命令不带快捷键，改过的命令旁边的箭头可恢复原有按键。`settings.json` 里的 `shortcuts` 保存同样的内容，按命令列出按键，例如 `"shortcuts": {"clear": ["ctrl-alt-l"]}`。Tab、Shift-Tab、F6 和 Shift-F6 不能被占用：它们用于移动焦点，在终端里则交给程序。

| | macOS | Windows 和 Linux |
|---|---|---|
| 新建会话 | Cmd-T | Ctrl-Shift-T |
| 关闭会话 | Cmd-W | Ctrl-Shift-W |
| 会话 1 到 8、最后一个 | Cmd-1 到 Cmd-8、Cmd-9 | Alt-1 到 Alt-8、Alt-9 |
| 下一个、上一个会话 | Ctrl-Tab、Ctrl-Shift-Tab | Ctrl-Tab、Ctrl-Shift-Tab |
| 会话栏 | Cmd-B | Ctrl-Shift-B |
| 右侧栏 | Cmd-Alt-B | Ctrl-Shift-Alt-B |
| 拷贝、粘贴 | Cmd-C、Cmd-V | Ctrl-Shift-C、Ctrl-Shift-V；在 Windows 上 Ctrl-V 也粘贴，Ctrl-Insert 拷贝、Shift-Insert 粘贴 |
| 拷贝选中文字，没有选中时粘贴 | 右键，需打开设置 › 终端 › 右键粘贴 | 右键，需打开同一开关；Windows 上默认打开 |
| 全选 | Cmd-A | Ctrl-Shift-A |
| 查找 | Cmd-F | Ctrl-Shift-F |
| 清屏并清空历史 | Cmd-K | Ctrl-Shift-K |
| 放大、缩小、重置大小 | Cmd-=、Cmd-minus、Cmd-0 | Ctrl-=、Ctrl-minus、Ctrl-0 |
| 打开链接（指针在上面时显示下划线） | Cmd-点按 | Ctrl-点按 |
| 设置 | Cmd-, | Ctrl-, |
| 最小化 | Cmd-M | |
| 退出 | Cmd-Q | Ctrl-Shift-Q |
